# Sales Business Analytics

## Overview
A portfolio project analyzing **600 synthetic sales transactions** using Python, Pandas, and SQL-style business analysis.

> **Data note:** The dataset is synthetic and created for portfolio/learning purposes. It does not represent a real company or real customer transactions.

## Objectives
- Clean and validate transactional sales data.
- Calculate revenue, cost, profit, and profit margin.
- Summarize performance by region and product category.
- Demonstrate SQL aggregation and grouping queries.
- Export reproducible business-analysis results.

## Technologies
- Python
- Pandas
- NumPy
- SQL
- CSV / tabular data analysis
- Aggregation and business metrics

